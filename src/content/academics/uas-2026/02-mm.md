## Overview

Kayaknya gini kata pak guru yang di ujikan konsepnya aja bukan coding.

### 1. Konsep CRUD

**Yang ditanyakan:** Peserta didik diminta menjelaskan pengertian CRUD (Create, Read, Update, Delete), kepanjangan, dan fungsi masing-masing operasi dalam aplikasi database.  
**Jawaban:**

- Create = menambah data baru.
- Read = menampilkan/mengambil data.
- Update = mengubah data yang ada.
- Delete = menghapus data.  
  👉 Empat operasi dasar untuk mengelola data.

---

### 2. Penerapan CRUD di VB.NET

**Yang ditanyakan:** Analisis proses CRUD pada aplikasi pendataan siswa (NIS, nama, kelas, alamat).  
**Jawaban:**

- Create: form input → simpan data siswa ke database.
- Read: tampilkan data siswa di DataGridView.
- Update: edit data siswa lalu simpan perubahan.
- Delete: hapus data siswa dari database.  
  👉 Semua operasi dihubungkan dengan query SQL sederhana.

---

### 3. Troubleshooting CRUD

**Yang ditanyakan:** Identifikasi penyebab dan solusi jika data tidak tersimpan ke database pada aplikasi CRUD VB.NET.  
**Jawaban:**

- Penyebab: koneksi database tidak aktif, query salah, tipe data tidak sesuai.
- Solusi: cek koneksi, perbaiki query, pastikan field cocok dengan tipe data.

---

### 4. DataGridView

**Yang ditanyakan:** Jelaskan fungsi dan cara penggunaan DataGridView dalam aplikasi CRUD VB.NET.  
**Jawaban:**

- Fungsi: menampilkan data tabel dalam bentuk grid.
- Bisa dipakai untuk melihat, memilih, dan mengedit data.  
  👉 Intuitif: seperti lembar Excel di dalam aplikasi.

---

### 5. Komponen Form VB.NET

**Yang ditanyakan:** Jelaskan fungsi komponen form: Label, TextBox, Button, ComboBox, RadioButton.  
**Jawaban:**

- Label = teks penjelas.
- TextBox = input teks.
- Button = aksi (simpan, hapus).
- ComboBox = pilihan dropdown.
- RadioButton = pilihan tunggal.

---

### 6. RadioButton vs CheckBox

**Yang ditanyakan:** Jelaskan perbedaan fungsi RadioButton dan CheckBox dalam aplikasi VB.NET.  
**Jawaban:**

- RadioButton = hanya bisa pilih satu dari beberapa opsi.
- CheckBox = bisa pilih lebih dari satu.  
  👉 Bedanya: eksklusif vs multiple choice.

---

### 7. Dampak Tidak Ada Fitur Update

**Yang ditanyakan:** Analisis permasalahan jika aplikasi CRUD tidak memiliki fitur Update.  
**Jawaban:**

- Data jadi tidak akurat.
- User harus hapus lalu tambah data baru.
- Membuat database tidak efisien.

---

### 8. phpMyAdmin & MySQL

**Yang ditanyakan:** Jelaskan fungsi phpMyAdmin, cara membuat database/tabel, dan tipe data MySQL yang umum digunakan.  
**Jawaban:**

- phpMyAdmin = alat berbasis web untuk kelola MySQL.
- Bisa buat database, tabel, edit data tanpa coding.
- Tipe data umum: INT (angka), VARCHAR (teks), DATE (tanggal).

---

### 9. Query SQL Dasar

**Yang ditanyakan:** Jelaskan fungsi query `SELECT * FROM tb_barang` dalam operasi CRUD.  
**Jawaban:**

- Query ini menampilkan semua data dari tabel `tb_barang`.
- Dipakai untuk operasi **Read**.

---

### 10. Perancangan Aplikasi Data Buku

**Yang ditanyakan:** Rancang aplikasi manajemen data buku perpustakaan dengan form login dan CRUD. Jelaskan struktur tabel, alur kerja, dan komponen form.  
**Jawaban:**

- Struktur tabel: id_buku, judul, pengarang, tahun, status.
- Alur: login → akses form → tambah/edit/hapus buku.
- Komponen form: TextBox (judul), ComboBox (kategori), Button (simpan).
