## Overview

Kisi kisi ppb kurang lebih sama aja kayak tahun kemarin 👇  

---

### 1. Native vs Hybrid

- **Native:** Dibangun khusus untuk satu platform (Android/iOS). Bahasa: Kotlin, Swift. Teknologi: Android Studio, Xcode.  
- **Hybrid:** Satu kode untuk banyak platform. Bahasa: JavaScript, Dart. Teknologi: React Native, Flutter.

---

### 2. Tahapan SDLC Mobile

1. **Planning:** Menentukan tujuan & kebutuhan.  
2. **Design:** Membuat rancangan UI/UX & arsitektur.  
3. **Development:** Menulis kode aplikasi.  
4. **Testing:** Memastikan aplikasi bebas bug.  
5. **Deployment:** Merilis ke store.  
6. **Maintenance:** Update & perbaikan rutin.

---

### 3. Desain UI Ramah Pengguna

1. Navigasi sederhana.  
2. Konsistensi warna & ikon.  
3. Responsif di berbagai ukuran layar.

---

### 4. Framework/Library

- **Keuntungan:** Cepat, efisien, banyak dukungan komunitas.  
- **Kekurangan:** Terbatas kustomisasi, ketergantungan versi.  
- **Contoh:** Flutter, React Native, Ionic.

---

### 5. Debugging & Testing

- **Debugging:** Mencari & memperbaiki error kode.  
- **Testing:** Memeriksa fungsi aplikasi berjalan benar.  
Keduanya penting untuk kualitas & stabilitas aplikasi.

---

### 6. Jenis Database Mobile

| Jenis | Kelebihan | Kekurangan |
|-------|------------|------------|
| SQLite | Ringan, offline | Kurang cocok untuk data besar |
| Realm | Cepat, mudah digunakan | Ukuran file besar |
| Firebase | Real-time, cloud | Bergantung koneksi internet |

---

### 7. REST vs GraphQL

- **REST:** Endpoint terpisah per resource. Contoh: `GET /users`.  
- **GraphQL:** Satu endpoint, query fleksibel. Contoh: `query { users { name } }`.

---

### 8. Testing & Debugging (Konsep)

- **Testing:** Validasi fungsi sesuai kebutuhan.  
- **Debugging:** Perbaikan kesalahan logika/kode.  
Keduanya menjaga aplikasi tetap stabil & siap produksi.

---

### 9. UI vs UX

- **UI:** Tampilan visual (warna, tombol, layout).  
- **UX:** Pengalaman pengguna (alur, kenyamanan, efisiensi).

---

### 10. Web Server Populer

Apache (xampp), Nginx, Node.js, Django, LiteSpeed.
